3-2. 파인튜닝 방법론

파인튜닝이란 이미 만들어진 범용 AI 모델을 우리 업무에 맞게 추가 학습시키는 과정입니다. 처음부터 AI를 만드는 것이 아니라, 이미 한국어를 할 줄 아는 AI에게 "소상공인 업무"라는 전문 분야를 가르치는 것입니다.

파인튜닝 전 (범용 AI)

리뷰: "갈비탕이 맛있었어요"

AI 답변: "리뷰 감사합니다."

→ 성의 없고, 업종 맥락 없음

파인튜닝 후 (전문화 AI)

리뷰: "갈비탕이 맛있었어요"

AI 답변: "감사합니다! 저희 갈비탕은 매일 새벽 한우 사골을 8시간 우려내고 있습니다. 다음에 오시면 된장찌개도 추천드려요!"

→ 업종 이해, 메뉴 추천, 재방문 유도

전체 과정 요약

  • 1단계: 범용 AI 모델을 가져옴 (Qwen 7B — 무료 오픈소스, 이미 한국어 가능)
  • 2단계: "질문-정답" 쌍 데이터를 대량 준비 (예: 리뷰 → 모범 답글 5만 건)
  • 3단계: GPU에서 이 데이터로 추가 학습 시작 (2~4시간)
  • 4단계: 결과 테스트 → 품질 부족하면 데이터 보강 후 재학습
  • 5단계: 완성된 모델을 서비스에 배포 → 비용 ₩0으로 AI 서비스 운영

LoRA — 효율적 학습 기법

모델의 70억 개 매개변수를 전부 수정하면 GPU 8장에 며칠이 걸립니다.
LoRA는 70억 개 중 0.1% (약 700만 개)만 수정하여 GPU 1장, 2~4시간으로 같은 효과를 냅니다.

비유: 의사 면허(원본 모델)는 그대로 두고, 피부과 전문의 자격증(LoRA 어댑터)만 새로 취득하는 방식

학습 데이터 구성 계획

3-4. GPU가 필요한 이유

왜 GPU가 필요한가?

  • LLM 파인튜닝은 고성능 GPU 없이 불가능 — 7B 모델의 LoRA 학습에도 최소 24GB VRAM 필요. H100 (80GB)이면 13B까지 가능
  • 추론 서빙에도 GPU 필수 — 실시간 텍스트 생성은 GPU 없이 실용적 속도 불가. H100 1장으로 동시 50+ 요청 처리
  • 창업 초기 인프라 한계 — H100 구매 5,000만원+, 클라우드 임대 월 500만원+. 정부 지원으로 해소 가능

배점 15점 — 연구 구체성, 전문성, 역량, 실적

5-1. 핵심 연구 주제

1. 한국어 소상공인 도메인 적응 (Domain Adaptation)

  • 범용 LLM을 한국 소상공인 업무 맥락에 특화
  • 16개 업종별 톤, 용어, 패턴 학습
  • 업종 코드만 입력하면 해당 업종에 맞는 응답 자동 생성

2. 멀티태스크 파인튜닝 (Multi-task Fine-tuning)

  • 하나의 모델로 견적서/리뷰/챗봇/웹사이트/마케팅 5가지 태스크
  • 태스크별 프롬프트 프리픽스로 전환
  • 모델 수를 줄여 서빙 비용 최소화

3. 경량화 및 추론 최적화

  • GPTQ/AWQ 양자화로 모델 크기 75% 축소
  • vLLM PagedAttention으로 동시 처리량 극대화

용어 설명

본 계획서에 사용된 주요 용어를 쉽게 풀어 설명합니다
용어설명
GPU
하드웨어		Graphics Processing Unit. 원래 그래픽 처리용이지만, AI 학습과 추론에 필수적인 고성능 연산 장치. NVIDIA H100이 현재 최고 성능 GPU.
LLM
AI 모델		Large Language Model (대규모 언어 모델). ChatGPT, Claude처럼 텍스트를 이해하고 생성하는 AI. 수십~수천억 개의 매개변수(파라미터)로 구성.
파인튜닝
(Fine-tuning)
AI 기술		이미 만들어진 범용 AI 모델을 특정 분야 데이터로 추가 학습시켜 전문화하는 기술. 처음부터 만드는 것보다 훨씬 빠르고 저렴함.
비유: 의대 졸업생(범용 LLM)을 피부과 전문의(파인튜닝)로 수련시키는 것
LoRA
AI 기술		Low-Rank Adaptation. 모델 전체를 학습하지 않고 일부분만 효율적으로 학습하는 기법. GPU 1장으로도 대형 모델을 파인튜닝할 수 있게 해줌.
추론 (Inference)
AI 기술		학습이 완료된 AI 모델이 실제로 질문에 답하거나 텍스트를 생성하는 과정. "학습 = 공부", "추론 = 시험" 으로 이해하면 됨.
양자화
(Quantization)
AI 기술		AI 모델의 숫자 정밀도를 낮추어 크기를 줄이는 기술. 성능 손실은 최소화하면서 모델 크기를 50~75% 줄일 수 있음. 더 적은 GPU로 더 빠르게 실행 가능.
매개변수
(파라미터, Parameter)
AI 용어		AI 모델이 학습한 "지식"이 저장되는 숫자들. AI의 두뇌 세포 같은 것. 7B = 70억 개. 많을수록 똑똑하지만 더 큰 GPU가 필요함.
70억 개: 노트북에서 실행 가능 / 700억 개: 고성능 GPU 필요 / 1조 개 이상: 대형 데이터센터급 (ChatGPT, Claude)
VRAM
하드웨어		Video RAM. GPU 전용 메모리. AI 모델을 실행하려면 모델 전체가 VRAM에 올라가야 함. H100은 80GB VRAM으로 7B~13B 모델 학습 가능.
API
소프트웨어		Application Programming Interface. 프로그램끼리 통신하는 방법. Claude API = Claude에게 질문을 보내고 답변을 받는 통로. 사용할 때마다 비용 발생.
SaaS
비즈니스		Software as a Service. 설치 없이 웹에서 바로 사용하는 소프트웨어 서비스. contavelo.ai가 SaaS — 브라우저에서 접속해서 사용.
MVP
비즈니스		Minimum Viable Product (최소 기능 제품). 핵심 기능만 넣어 빠르게 만든 첫 번째 버전. "완벽하진 않지만 동작하는 제품".
MRR
비즈니스		Monthly Recurring Revenue (월간 반복 매출). 구독 서비스의 월 매출. MRR ₩500만 = 매월 꾸준히 500만원이 들어옴.
데이터 플라이휠
(Data Flywheel)
전략		사용자가 늘면 데이터가 쌓이고 → 데이터가 쌓이면 AI가 좋아지고 → AI가 좋아지면 사용자가 더 느는 선순환 구조. 경쟁사가 따라오기 어려운 "해자(moat)"를 만드는 전략.
vLLM
소프트웨어		AI 모델을 빠르게 서빙(서비스)하기 위한 오픈소스 도구. 여러 사용자의 요청을 동시에 처리할 수 있게 최적화됨.
DeepSpeed
소프트웨어		Microsoft가 만든 AI 학습 최적화 도구. 적은 GPU로도 큰 모델을 학습할 수 있게 메모리를 효율적으로 관리.
Hugging Face
플랫폼		AI 모델 공유 플랫폼. "AI 세계의 GitHub". 누구나 만든 모델을 올리고 다운받을 수 있음. Qwen, EXAONE 등 오픈소스 모델이 여기에 공개됨.
P95 레이턴시
성능		전체 요청 중 95%가 이 시간 안에 응답됨을 의미. "P95 = 0.5초" = 100번 요청하면 95번은 0.5초 안에 답변. 나머지 5번은 더 걸릴 수 있음.
도메인 적응
(Domain Adaptation)
AI 기술		범용 AI를 특정 분야에 맞게 전문화하는 과정. "한국 소상공인 도메인 적응" = AI가 한국 소상공인의 업무, 용어, 맥락을 잘 이해하게 만드는 것.
Tier
비즈니스		서비스 등급. Tier 1(무료) → Tier 2(프로, 월 구독) → Tier 3(맞춤 개발). 단계별로 더 많은 기능 제공.
에폭 (Epoch)
AI 용어		AI 학습에서 전체 데이터를 한 번 학습하는 단위. "3 에폭 = 전체 데이터를 3번 반복 학습". 보통 3~10 에폭이면 학습 완료.
